# Эмулятор ПВУ-1 на OPC UA

OPC UA сервер, который ведёт себя как приточно-вытяжная установка ПВУ-1 с чертежа: пускается по шагам, регулирует температуру в помещении, срабатывает защита от замерзания, и время от времени у него что-то ломается. Имена тегов совпадают с переменными страницы `pvu.html`, поэтому привязка делается один к одному.

## Запуск

**Windows.** Нужен Python 3.10 или новее. Запустите `run_emulator.bat`: при первом запуске он создаст окружение `.venv` и поставит библиотеку `asyncua`, затем запустит сервер.

**Вручную:**

```
python -m venv .venv
.venv\Scripts\activate          (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
python pvu_emulator.py
```

В консоли появится адрес сервера и журнал событий. Остановка — Ctrl+C. Если клиент на другом компьютере, откройте в брандмауэре входящий TCP-порт 4891.

## Подключение

| | |
|---|---|
| Адрес | `opc.tcp://<IP-компьютера>:4891/` |
| Безопасность | None, анонимный вход |
| Пространство имён | `urn:pvu1:emulator` (обычно `ns=2`) |
| NodeId тега | `ns=2;s=PVU1.<имя>`, например `ns=2;s=PVU1.room_temp` |
| Период обновления | 200 мс, пишутся только изменившиеся значения |

В дереве сервера теги разложены по папкам объекта `PVU1`: Room, Supply, Exhaust, Heater, Unit, Commands. NodeId от папки не зависит.

## Управление

**Через теги** (подходит любой SCADA): запишите `true` в `cmd_start`, `cmd_stop`, `cmd_reset` или `cmd_replace_filter`. Эмулятор выполнит команду и вернёт тег в `false`. Уставку пишите в `room_sp`, значение ограничивается диапазоном 16–28 °C. Ключи «Местное / Дистанционное» переключаются записью в `key_sa_local` и `key_ea_local`.

**Через методы** объекта `PVU1`: `Start()`, `Stop()`, `ResetAlarms()`, `SetSetpoint(Double)`, `ReplaceFilter()`, `InjectFault(String)`. Все возвращают `Boolean`. `InjectFault("clear")` снимает текущую неисправность.

Команды страницы `pvu.html` (событие `pvu:command`) ложатся так: `start` → `cmd_start`, `stop` → `cmd_stop`, `setpoint` → `room_sp`.

## Как работает автоматика

- **Пуск.** Открываются заслонки 6з и 6и, насос работает. Если обратная вода холоднее 35 °C, клапан 1в открывается полностью на прогрев калорифера (до 20 с). Затем пускается вытяжной вентилятор, через 5 с — приточный. Когда приточный набрал скорость, состояние «Работа».
- **Работа.** Регулятор TICAS 1б держит температуру в помещении клапаном 1в (ПИ-закон). Если воздух за калорифером холоднее 10 °C или обратная вода холоднее 25 °C, клапан принудительно приоткрывается.
- **Стоп.** Вентиляторы останавливаются, заслонки закрываются. Зимой (наружный воздух ниже +5 °C) насос продолжает работать, а клапан держит обратную воду около 30 °C.
- **Блокировки.** Нет перепада на вентиляторе (PDA 4б, PDA 5б) → аварийный останов. Воздух за калорифером ниже 5 °C (TS 2в) → защита от замерзания: вентиляторы стоят, заслонки закрыты, клапан открыт на 100 %, насос работает. Из блокировки выводит команда сброса. По умолчанию эмулятор сам сбрасывает блокировку не раньше чем через 60 с после срабатывания, если причина к этому времени ушла (иначе проверяет снова каждые 30 с), и снова пускает установку, если её не останавливали.
- **Остальные аварии.** Засорение фильтра (PDA 3б, больше 2,5 мбар) висит до замены фильтра. Если фильтр не заменить, через 4 минуты его «меняет сервисная служба». Низкая обратная вода (TIS 2г, ниже 20 °C) и отклонение температуры в помещении больше чем на 3 °C дольше 2 минут (TICAS 1б) снимаются сами, когда параметр вернулся в норму.

## Случайные неисправности

По умолчанию неисправность появляется в среднем раз в 3 минуты, держится случайное время и «ремонтируется». Одновременно активна только одна. Её текст виден в теге `fault_active`.

| Имя для `InjectFault` | Что происходит | Какие аварии получите |
|---|---|---|
| `supply_fan_belt` | Обрыв ремня: двигатель крутится, колесо стоит | `alarm_fan_sa`, аварийный останов |
| `exhaust_fan_trip` | Сработала защита двигателя вытяжного вентилятора | `alarm_fan_ea`, аварийный останов |
| `pump_trip` | Отказ циркуляционного насоса | `alarm_freeze` через ~1 мин, затем `alarm_water` |
| `heat_loss` | Пропал теплоноситель в сети | `alarm_water`, затем `alarm_freeze` |
| `valve_stuck` | Заклинило привод клапана (почти закрыт или почти открыт) | `alarm_room`; если закрыт — ещё `alarm_water` |
| `filter_clog` | Фильтр забивается в 40 раз быстрее | `alarm_filter` |
| `room_gains` | Большие теплопритоки в помещение | `alarm_room` |
| `local_key` | Ключ GKS 6ж переведён в «Местное» | без аварии, `key_sa_local = true` |

Кроме тегов, каждая запись журнала уходит OPC UA событием от объекта Server. Поле Severity: 200 — информация, 300 — норма, 500 — внимание, 800 — авария.

## Параметры запуска

```
python pvu_emulator.py --help
```

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `--port` | 4891 | Порт OPC UA |
| `--host` | 0.0.0.0 | Адрес, на котором слушать |
| `--speed` | 1 | Ускорение времени модели; 10 — всё происходит в 10 раз быстрее |
| `--fault-interval` | 180 | Среднее время между неисправностями, с модели |
| `--no-faults` | | Без случайных неисправностей |
| `--fault NAME` | | Сразу включить неисправность из таблицы выше |
| `--auto-reset` | 60 | Автосброс блокировки через N с после срабатывания, если причина ушла; 0 — сброс только оператором |
| `--no-autostart` | | Не пускать установку при старте эмулятора |
| `--seed` | | Зерно случайных чисел, чтобы сценарий повторялся |

Параметры передаются и через `run_emulator.bat`, например `run_emulator.bat --speed 5 --fault-interval 60`.

## Проверочный клиент

```
python check_client.py                    — прочитать все теги
python check_client.py --watch            — сводка каждые 2 с и OPC UA события
python check_client.py --cmd stop         — команда через тег cmd_stop
python check_client.py --sp 22.5          — уставка через метод SetSetpoint
python check_client.py --fault pump_trip  — включить неисправность; clear — снять
python check_client.py --url opc.tcp://192.168.1.10:4891/
```
