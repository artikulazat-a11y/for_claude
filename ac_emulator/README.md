# Эмулятор кондиционера — Modbus TCP сервер

Имитатор инверторной сплит-системы для отладки SCADA, ПЛК и панелей оператора.
Клиент включает и выключает кондиционер, задаёт уставку, режим и скорость
вентилятора; температура в помещении, приточного воздуха и обороты вентилятора
меняются плавно, как у настоящего агрегата. Раз в сутки или реже случается
случайная авария, которая останавливает кондиционер до сброса.

## Запуск

Нужен Python 3.10+, сторонние библиотеки не требуются.

```
python -m ac_emulator                 # порт 502
python -m ac_emulator --port 5020     # в Linux порты ниже 1024 требуют прав root
```

В Windows можно запустить `run_ac_emulator.bat` из корня репозитория.

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `--host` | `0.0.0.0` | адрес для прослушивания |
| `--port` | `502` | TCP-порт Modbus |
| `--time-scale` | `1` | ускорение модельного времени: `60` — минута за секунду, сутки за 24 минуты |
| `--no-faults` | — | отключить случайные аварии |
| `--seed` | случайно | зерно генератора (повторяемые аварии и шум) |
| `--tick` | `0.1` | шаг расчёта модели, с |

Unit ID (Slave ID) — любой, ответ приходит с тем же номером. Поддерживаются
функции 01, 02, 03, 04, 05, 06, 15, 16.

## Карта регистров

Адреса указаны **с нуля**, как они передаются в запросе Modbus. Если SCADA
нумерует регистры с единицы (нотация 4xxxx/3xxxx), прибавьте 1:
уставка — 40002, температура в помещении — 30001.

Температуры — знаковое 16-битное целое в десятых долях градуса:
`235` = 23.5 °C, `65486` (-50) = -5.0 °C.

### Coils (функции 01, 05, 15)

| Адрес | Доступ | Назначение |
|---|---|---|
| 0 | R/W | Включение: 1 — вкл, 0 — выкл |
| 1 | W | Сброс аварии: запись 1 (читается 0) |

### Discrete Inputs (функция 02)

| Адрес | Назначение |
|---|---|
| 0 | Работает (включён и нет аварии) |
| 1 | Авария |
| 2 | Компрессор работает |
| 3 | Вентилятор вращается |
| 4 | Охлаждение |
| 5 | Обогрев |

### Holding Registers (функции 03, 06, 16)

| Адрес | Назначение | Значения |
|---|---|---|
| 0 | Включение (дублирует coil 0) | 0 — выкл, 1 — вкл |
| 1 | Уставка температуры, 0.1 °C | 160..300 (16.0..30.0 °C), по умолчанию 220 |
| 2 | Режим | 0 — авто, 1 — охлаждение, 2 — обогрев, 3 — вентиляция |
| 3 | Скорость вентилятора | 0 — авто, 1 — низкая (35 %), 2 — средняя (65 %), 3 — высокая (100 %) |
| 4 | Сброс аварии (дублирует coil 1) | запись 1; читается 0 |
| 5 | Тестовая авария | запись кода 1..5 вызывает аварию сразу; читается 0 |

Запись значения вне диапазона отклоняется исключением Modbus 03
(Illegal Data Value), обращение к несуществующему адресу — исключением 02.

### Input Registers (функция 04)

| Адрес | Назначение | Единицы |
|---|---|---|
| 0 | Температура в помещении | 0.1 °C |
| 1 | Температура на улице | 0.1 °C |
| 2 | Температура приточного воздуха | 0.1 °C |
| 3 | Скорость вентилятора | % |
| 4 | Обороты вентилятора | об/мин (0..1200) |
| 5 | Производительность компрессора | % |
| 6 | Состояние | 0 — выкл, 1 — ожидание (уставка достигнута), 2 — охлаждение, 3 — обогрев, 4 — вентиляция, 5 — авария |
| 7 | Код аварии | 0 — нет, 1..5 — см. ниже |
| 8 | Слово состояния | биты: 0 — вкл, 1 — работает, 2 — компрессор, 3 — вентилятор, 4 — охлаждение, 5 — обогрев, 6 — авария |
| 9 | Потребляемая мощность | Вт |
| 10 | Счётчик аварий с момента запуска | шт. |

### Коды аварий

| Код | Авария |
|---|---|
| 1 | Перегрев компрессора |
| 2 | Высокое давление хладагента |
| 3 | Низкое давление хладагента (утечка) |
| 4 | Отказ двигателя вентилятора |
| 5 | Обрыв датчика температуры в помещении |

## Как ведёт себя модель

- **Включение.** Вентилятор разгоняется плавно (5 %/с), компрессор набирает
  производительность 4 %/с. При выключении оба плавно останавливаются.
- **Уставка.** Инвертор держит мощность пропорционально отклонению температуры
  от уставки: далеко от уставки — 100 %, у уставки — минимум 20 %. Гистерезис
  ±0.5 °C: при достижении уставки компрессор отключается, вентилятор в режиме
  «авто» крутится на 30 %. Помещение охлаждается или нагревается примерно на
  0.6 °C в минуту на полной мощности.
- **Режим «авто»** сам выбирает охлаждение или обогрев; сменить направление
  он может только при отклонении больше 2 °C, чтобы не «качаться».
- **Улица и теплопотери.** Уличная температура меняется по суточному графику
  (18 °C в 5 утра, 30 °C в 17 часов), помещение без кондиционера медленно
  стремится к ней.
- **Случайная авария** возникает не чаще раза в модельные сутки: следующая
  назначается в случайный момент через 24..48 часов после предыдущей (первая —
  в течение 1..24 часов после запуска). Авария происходит только когда
  кондиционер работает в режиме охлаждения, обогрева или авто; если в
  назначенный момент он выключен, авария переносится. При аварии компрессор и
  вентилятор останавливаются, состояние = 5, взводится бит «Авария». Работа
  возобновляется после сброса (coil 1 или holding-регистр 4), если кондиционер
  остаётся включённым.
- **Тестовая авария** (holding-регистр 5) нужна, чтобы проверить аварийную
  сигнализацию в SCADA, не дожидаясь случайной.

Для быстрой проверки аварий запустите с `--time-scale 3600`: модельные сутки
пройдут за 24 секунды.

## Пример опроса (pymodbus)

```python
from pymodbus.client import ModbusTcpClient

c = ModbusTcpClient("127.0.0.1", port=502)
c.connect()
c.write_coil(0, True)              # включить
c.write_register(1, 240)           # уставка 24.0 °C
r = c.read_input_registers(0, count=11).registers
print("в помещении", r[0] / 10, "°C, вентилятор", r[3], "%, состояние", r[6])
c.write_coil(1, True)              # сбросить аварию
```
