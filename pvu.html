      Журнал событий

        Привязка переменных

        window.PVU

        Значения передаются через объект window.PVU или через postMessage, если страница встроена во фрейм. Первое же внешнее значение выключает демо-режим. Наведите курсор на прибор на схеме, чтобы увидеть его переменные.

        // одно значение
PVU.set('room_temp', 21.4);

// несколько значений за раз
PVU.set({ fan_sa_run: true, fan_sa_speed: 80, valve_pos: 45 });

// из родительского окна, если страница открыта во фрейме
frame.contentWindow.postMessage({ type: 'pvu:set', values: { room_temp: 21.4 } }, '*');

// команды оператора: start, stop, setpoint (приходят и родителю как 'pvu:command')
window.addEventListener('pvu:command', e => console.log(e.detail));

// выключить демо до загрузки страницы
window.PVU_CONFIG = { demo: false };
